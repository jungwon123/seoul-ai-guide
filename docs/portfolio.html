요구사항

  • LLM 응답은 토큰 단위로 점진 도착 → 실시간 스트리밍 필수
  • 네이티브 EventSource는 단절 시 비멱등 GET 자동 재연결 → LLM 응답이 처음부터 재실행되는 루프 발생
  • 응답 "준비 단계"에서도 사용자가 확실히 취소 가능해야 함

해결과정

  • fetch + AbortController 기반 커스텀 SSE 파서로 EventSource 대체 → 자동 재연결 제거로 재실행 루프 차단
  • 프레임 버퍼링 · heartbeat 무시 · event/data.type 폴백 판별 직접 구현
  • 취소 시 abort() → 스트림 중단 + 질문 말풍선 제거 + 입력 텍스트 복원

결과

  • 단절·취소 시 LLM 재실행 루프 제거
  • 준비 단계 포함 어느 시점에서도 취소 버튼 확정 동작
  • 토큰 누적 렌더로 즉각적인 응답 체감

  • 라이브 SSE(delta)와 DB 저장본(content) 필드 형태가 다르고 snake/camel 혼재

  • type 기반 discriminated-union BlockRenderer로 블록별 컴포넌트 디스패치
  • 좌표 보유 블록에서 마커 자동 추출 → mapStore 전달 (단방향 흐름)

결과

  • BE 블록 스키마 변경 시 어댑터 한 곳만 수정 → 변경 격리
  • 채팅·지도가 동일 데이터에서 일관 렌더
  • OpenAPI 자동 생성 타입(1,470줄)과 결합해 FE/BE 계약 동기화
